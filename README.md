## 🤖 About This README

> Este README se genera **automáticamente** cada vez que subo un nuevo CV en formato PDF.

### Cómo funciona

```
📄 CV (PDF) → 📦 S3 Bucket → ⚡ AWS Lambda → 📝 README.md → 🐙 GitHub
```

1. **Watch**: Un daemon local (`fswatch` + `launchd`) monitorea la carpeta de CVs
2. **Upload**: Detecta el PDF con versión más alta y lo sube a S3
3. **Parse**: Una Lambda en TypeScript extrae los datos del PDF con `pdf-parse`
4. **Generate**: Genera este README con el formato que ves acá
5. **Publish**: Actualiza el archivo `README.md` vía GitHub API
